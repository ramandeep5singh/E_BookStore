## Project Overview

E_BookStore is a basic e-commerce platform prototype for buying and managing books online. It demonstrates core web development concepts including user authentication, database persistence, and admin workflows—all relevant learning objectives at that stage.

### What This Project Covers

**User-Facing Features:**
- Book browsing by category (fiction, non-fiction, academic)
- User registration and secure login
- Shopping cart and order placement
- Cash on Delivery (COD) payment workflow

**Admin Features:**
- Order management and status updates
- Inventory control

**Technical Stack:**
- **Backend**: Java (JDK 8)
- **Database**: MySQL
- **Frontend**: HTML, CSS, JavaScript with Bootstrap
- **Server**: Apache Tomcat

## Known Limitations (Intentional for Learning Phase)

- **Payment Processing**: Only COD implemented (online payments not integrated)
- **Search & Filtering**: Basic category browsing; advanced search not implemented
- **Architecture**: Monolithic approach; would use layered/microservices architecture today
- **Testing**: Manual testing only; no automated test coverage

These limitations reflect the scope of a college project and early internship work. Modern production systems I work on apply significantly more rigorous evaluation, testing, and architectural patterns.
